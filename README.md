# Math Department Deep Structure Research

Research project exploring latent structure in a mathematics department using graph-based and geometric methods. The repository contains work from multiple research subteams, including clustering, spectral analysis, and barycenter-based approaches.

## Project Overview

The project investigates whether meaningful structural patterns can be recovered from relational data representing a mathematics department. The broader workflow combines network representation, clustering, spectral methods, and geometric summaries to study hidden organization and similarity patterns in the data.

## Research Components

The repository includes several research directions:

- **Clustering** — grouping related observations or entities based on structural similarity
- **Spectral methods** — using eigenvalue/eigenvector-based graph structure to identify latent organization
- **Barycenter methods** — exploring geometric summaries and central representations in non-Euclidean spaces
- **Research reports and presentations** — documentation of methodology, experiments, and results

## PATHTREES Reference

This project references **PATHTREES** as an external research method / implementation for exploring tree-space geometry.

The `PATHTREES-main` materials in this repository and the separate [`PATHTREES`](https://github.com/ziqixu22/PATHTREES) repository are **reference materials and are not presented as my original standalone software project**.

PATHTREES was used to help understand computational approaches for constructing and exploring paths between phylogenetic trees in Billera-Holmes-Vogtmann (BHV) tree space. Our research project is broader and includes our own work in clustering, spectral analysis, and barycenter-based investigation.
